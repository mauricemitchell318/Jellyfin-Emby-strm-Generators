# Jellyfin-Emby-strm-Generators
A high-performance PowerShell script designed to parse IPTV/VOD M3U playlists and automatically generate structured .strm files organized by show name and season. (It extracts the .strm tv show or movie m3u in the file and creates folders for the name of the show placing seasons and episodes of it in the folder) Perfect for media servers like Jellyfin and Emby.
